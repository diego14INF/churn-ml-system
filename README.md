# churn-ml-system
End-to-end machine learning project focused on customer churn prediction. The project covers problem framing, baseline modeling, deep learning with PyTorch, experiment tracking with MLflow, cloud training and deployment using Azure Machine Learning, and production-oriented MLOps practices.

# End-to-End Customer Churn Prediction System

---

## Business Problem
Customer churn has a direct impact on revenue.  
The business objective is to **predict whether a customer will churn**, allowing the company to take action before the churn event occurs.

This is formulated as a **binary classification problem**.

---

## Dataset
- **Source:** Telco Customer Churn Dataset (Kaggle)  
- **Link:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The dataset contains customer demographics, service usage, and billing information.
